# Firmware / 固件

本目录是嵌入式固件实验的占位目录。

This directory is a placeholder for embedded firmware experiments.

当前生产原型由 Raspberry Pi 后端直接驱动 PCA9685 舵机，因此这里只保留 PlatformIO 项目骨架，供未来将部分硬件控制下放到微控制器时使用。

The current production prototype drives PCA9685 servos directly from the Raspberry Pi backend. This directory keeps only the PlatformIO project scaffold for a future microcontroller offload path.
